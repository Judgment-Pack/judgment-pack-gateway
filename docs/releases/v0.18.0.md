Gateway v0.18.0 adds read-only discovery of the installed web page adapter's research binding. A host can obtain the adapter's actual identity without fetching a page, inspecting a search connection or guessing its version.

## What an operator must do

Existing acquisition configurations keep their meaning. To use the new descriptor, invoke `adapter-web --describe-research` alone. It reads no stdin, connection, credential, processing configuration or network resource.

A host registering a page profile still verifies the installed program against its distribution, supplies its own Gateway authority/key and reviews the endpoint constraint. The descriptor's null endpoint grants no wildcard. Historical profiles and receipts are not rewritten; a fresh acquisition through a changed executable needs a profile that pins that executable's actual identity.

## Read-only page binding description (#287, closes #286)

- The closed version-1 descriptor carries the HTTP shape, actual executable name/version/digest, the `page` capability, null endpoint, empty fixed arguments, the existing page-read argument shape and the `attachment-v1` result name.
- Page reads, discovery and description use one identity helper. The adapters remain unstamped, as before: the reported version is the adapter's own, never a reconstructed Gateway release version.
- Required `url` and optional `site` are the request's only members. The descriptor's schema describes their shape; runtime byte, URL, public-network, robots and operator-policy checks still apply at acquisition.
- Duplicate or mixed description/read/discovery flags are refused before stdin. Description makes no acquisition, receipt, profile or permission.

Receipt version 3, engine configuration version 10, the connection catalogs and the frozen conformance corpus are unchanged. This release also records ADR-0017's acceptance (#284); its implementation shipped earlier.

## Verification and limits

The full adapter/core test suites, formatting and vet passed locally with Go 1.26.5. Focused websource and adapter-web race tests passed. Frozen conformance had zero disagreements across 30 canonical, 85 store, 54 witness and 25 witness-recovery vectors. Tests cover a non-default adapter version, own-executable digest, descriptor/acquisition identity parity, closed arguments and refusal of ambiguous flags.

An isolated Desk bundle built from the reviewed source reported the same descriptor identity as its manifest and executable digest. No live provider, account or public website was used. This does not establish page accuracy, public reachability, research quality or permission to contact anyone.

Independent clean-room Codex review of #287 found no actionable findings. Drafter and reviewer were OpenAI models, under the maintainer's requested Codex substitution; this is not a cross-vendor review.
